---
title: "Consultar API Key"
api: "GET /apiKeys/{id}"
description: "Retorna os detalhes de uma API Key (sem o secret)"
---

## Request

<ParamField path="id" type="string" required>
  UUID da API Key.
</ParamField>

<RequestExample>

```bash cURL
curl -X GET https://api.thalbank.com/apiKeys/e5f6a7b8-c9d0-1234-ef01-23456789abcd \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIs..."
```

</RequestExample>

<ResponseExample>

```json 200
{
  "status": true,
  "data": {
    "id": "e5f6a7b8-c9d0-1234-ef01-23456789abcd",
    "name": "Producao - Loja Principal",
    "sellerId": "f6a7b8c9-d0e1-2345-f012-3456789abcde",
    "createdAt": "2026-03-10T00:00:00.000Z"
  }
}
```

</ResponseExample>
