## Descricao

Retorna o saldo atual da wallet do seller. Todos os valores sao em **centavos**.

| Campo | Descricao |
|-------|-----------|
| `availableBalance` | Saldo disponivel para saque |
| `blockedBalance` | Saldo retido (disputas, reservas, periodo de retencao) |
| `totalBalance` | Soma de disponivel + bloqueado |

<RequestExample>

```bash cURL
curl -X GET https://api.thalbank.com/seller-wallet/gestao \
  -H "x-api-key: sua_api_key"
```

```javascript Node.js
const response = await fetch("https://api.thalbank.com/seller-wallet/gestao", {
  headers: { "x-api-key": process.env.THALPAY_API_KEY },
});
const { data } = await response.json();
console.log(`Disponivel: R$ ${(data.availableBalance / 100).toFixed(2)}`);
```

</RequestExample>

<Tip>
  Para converter centavos para reais: `valor / 100`. Exemplo: `1250000` centavos = R$ 12.500,00
</Tip>
