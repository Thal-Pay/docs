api: "GET /withdrawals/{id}"

---

## Descricao

Retorna os dados completos de um saque. Voce so tem acesso aos saques do seu proprio seller.

## Request

<ParamField path="id" type="string" required>
  UUID do saque.
</ParamField>

<RequestExample>

```bash cURL
curl -X GET https://api.thalbank.com/withdrawals/c3d4e5f6-a7b8-9012-cdef-123456789012 \
  -H "x-api-key: sua_api_key"
```

</RequestExample>
