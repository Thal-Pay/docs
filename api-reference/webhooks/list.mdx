## Descricao

Retorna todos os webhooks configurados para o seu seller.

## Request

<ParamField query="take" type="integer" default="10">
  Registros por pagina.
</ParamField>

<ParamField query="skip" type="integer" default="0">
  Offset de paginacao.
</ParamField>

<RequestExample>

```bash cURL
curl -X GET "https://api.thalpay.com/webhooks?take=10" \
  -H "x-api-key: sua_api_key"
```

</RequestExample>
